PLATFORM DEGERLENDIRME 2.3.0  (makrolu Excel)
=======================================================================

KULLANIM
  1. PLATFORM_DEGERLENDIRME.xlsm dosyasini acin.
  2. Ilk acista ustte cikan sari seritte "Icerigi Etkinlestir / Enable
     Content" deyin.
     Dosya internetten (GitHub) indirildiyse Windows makrolari tamamen
     engelleyebilir (kirmizi serit "Microsoft bu dosyadaki makrolari
     engelledi").  O zaman: Excel'i kapatin -> dosyaya sag tik ->
     Ozellikler -> alttaki "Engellemeyi kaldir / Unblock" kutusunu
     isaretleyin -> Tamam.  Bir kere yapmaniz yeter.
  3. LOAD REPORT  -> Hexagon raporunu (.xlsx) secin.  Analiz hemen yapilir.
  4. SAVE RESULT (.xlsx) -> sonucu makrosuz ayri bir Excel olarak
     kaydeder (ad: PartNo_SerialNo_PLATFORM.xlsx).
  5. CLEAR -> son analizi siler.

ANALYSIS sayfasi (sayfadaki yazilar Ingilizce)
  - Ustte parca bilgileri (Summary sayfasi): Part No, Serial No (ilk 5 hane),
    CMM, Date.
  - Sagda OVERALL RESULT: butun platformlar PASS ise yesil PASS, biri bile
    FAIL ise kirmizi FAIL.
  - Tablo: PLATFORM NO | OUT PROFILE .010 | OUT PROFILE .020 | AVERAGE |
    TOTAL POINT COUNT | %5 LIMIT | MAX |DEV| | PASS/FAIL (en sagda).
    Yalniz FAIL sebebi kirmizi: .010 sayisi siniri asarsa, .020 > 0 ise,
    ortalama +/-.004 disindaysa.
POINTS sayfasi: rapordaki gibi satir = platform, sutun = nokta;
  .005-.010 arasi sari, .010 ustu kirmizi.

OKUMA
  Platform sayfasi: A sutununda platform numarasi (1, 2, 3 ...), her SATIR
  bir platform.  B sutunu (basliginda "SPF": platformun maks/min degeri)
  nokta SAYILMAZ, atlanir.  C'den saga her sutun o platformun bir noktasi
  (PLATFORM_1 = 1. nokta).  Yalniz numarali satirlar okunur; tablonun
  altindaki tolerans satirlari alinmaz.  Bos hucre nokta sayilmaz.

KURAL (her platform, N = o platformdaki nokta sayisi)
  |sapma| <= .005              -> iceride (.010 profil)
  .005 < |sapma| <= .010       -> "OUT PROFILE .010" noktasi
  |sapma| > .010               -> "OUT PROFILE .020" noktasi
  PASS =  .020 noktasi YOK
          ve .010 noktasi sayisi < N x %5  (yuvarlanmaz: 39 nokta -> 1,95:
             1 nokta gecer, 2 nokta FAIL)
          ve |ortalama sapma| <= .004  (.008 profil)
  Tam .004 / .005 / .010 kabul (iceride sayilir).

KAYNAK (degistirmek isterseniz)
  xlsm\PlatformAnaliz.bas  makro kodu (Excel'de Alt+F11 ile de gorulur)
  xlsm\make_xlsm.py        .xlsm'i bastan uretir:  py xlsm\make_xlsm.py
                           (gerekir: py -m pip install xlsxwriter)
  xlsm\vba_bin.py          makroyu dosyanin icine yazan yardimci
