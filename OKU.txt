PLATFORM DEGERLENDIRME 2.0.0  (makrolu Excel)   created by EYALTIRIKLI
=======================================================================

KULLANIM
  1. PLATFORM_DEGERLENDIRME.xlsm dosyasini acin.
  2. Ilk acista ustte cikan sari seritte "Icerigi Etkinlestir / Enable
     Content" deyin.
     Dosya internetten (GitHub) indirildiyse Windows makrolari tamamen
     engelleyebilir (kirmizi serit "Microsoft bu dosyadaki makrolari
     engelledi").  O zaman: Excel'i kapatin -> dosyaya sag tik ->
     Ozellikler -> alttaki "Engellemeyi kaldir / Unblock" kutusunu
     isaretleyin -> Tamam.  Bir kere yapmaniz yeter.
  3. EXCEL YUKLE  -> Hexagon raporunu (.xlsx) secin.  Analiz hemen yapilir.
  4. SONUCU KAYDET (.xlsx) -> sonucu makrosuz ayri bir Excel olarak
     kaydeder (ad: PartNo_SerialNo_PLATFORM.xlsx).

ANALIZ sayfasi
  - Ustte parca bilgileri (Summary sayfasi): Part No, Serial No,
    Operation, Operator, CMM, NC W/S, Spindle, Date, Company, Location.
  - Sagda GENEL SONUC: butun platformlar PASS ise yesil PASS, biri bile
    FAIL ise kirmizi FAIL.
  - Tablo: PLATFORM NO | OUT PROFILE .010 | OUT PROFILE .020 | AVERAGE |
    TOTAL POINT COUNT | %5 LIMIT | MAX |DEV| | PASS/FAIL (en sagda).
    .010 sayisi sinirdaysa sari, siniri asarsa kirmizi; .020 > 0 kirmizi;
    ortalama +/-.004 disindaysa kirmizi.
NOKTALAR sayfasi: butun degerler; .005-.010 arasi sari, .010 ustu kirmizi.

OKUMA
  Platform sayfasi: A sutununda nokta sirasi (1, 2, 3 ...), B'den saga her
  sutun bir platform (#1, #2 ...).  Basliginda "SPF" gecen sutun (her
  noktadaki en buyuk deger) platform SAYILMAZ, atlanir.  Yalniz numarali
  satirlar okunur; tablonun altindaki tolerans satirlari alinmaz.  Bos
  hucre nokta sayilmaz.

KURAL (her platform, N = o platformdaki nokta sayisi)
  |sapma| <= .005              -> iceride (.010 profil)
  .005 < |sapma| <= .010       -> "OUT PROFILE .010" noktasi
  |sapma| > .010               -> "OUT PROFILE .020" noktasi
  PASS =  .020 noktasi YOK
          ve .010 noktasi sayisi <= N x %5  (tam sayiya yuvarlanir, ,5 yukari:
             40 -> 2, 30 -> 2, 45 -> 2, 50 -> 3; sinira esit gecer)
          ve |ortalama sapma| <= .004  (.008 profil)
  Tam .004 / .005 / .010 kabul (iceride sayilir).

KAYNAK (degistirmek isterseniz)

                           (gerekir: py -m pip install xlsxwriter)
  xlsm\vba_bin.py          makroyu dosyanin icine yazan yardimci
